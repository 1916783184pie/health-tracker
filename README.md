# 我的健康记录

手机优先的饮水 + 运动记录单页网站。清爽蓝白风、单列布局、无需登录，数据保存在当前浏览器（localStorage），刷新不丢失。

## 如何使用

- **电脑**：双击 `index.html`，用浏览器打开即可。
- **手机**：把 `index.html` 发送到手机（微信文件传输 / 网盘 / 局域网均可），用浏览器打开。也可以把文件放到任意静态托管上再访问（当前按要求未发布）。
- 别人首次打开时看到默认昵称「健康记录员」和空记录，互不干扰（各设备各自存储）。

## 数据模型（持久化路径）

存储位置：当前浏览器 `localStorage`，键名 `***`（代码字面值，见 index.html 的 `var KEY`）。

```json
{
  "nickname": "健康记录员",
  "activeSport": "跑步",
  "water": {
    "2026-11-15": [ { "ts": 1794703000000, "ml": 250 } ]
  },
  "ex": {
    "2026-11-15": {
      "跑步":   [ { "ts": 1794703100000, "km": 5.0, "min": 40 } ],
      "拉伸":   [ { "ts": 1794703200000, "min": 15 } ]
    }
  }
}
```

- 日期键为本地时区 `YYYY-MM-DD`；`ts` 为毫秒时间戳（用于显示时间与撤销定位）。
- 跨天后自动按新的一天渲染；历史日期数据保留在文件中。
- 清除浏览器站点数据即重置；换设备 / 换浏览器不共享。

## 新增其他运动项目

打开 `index.html`，在 `SPORTS` 配置数组中加一行即可，字段按实际需要设置：

```js
{ name: '骑行', km: true  }  // 记公里+分钟，自动计算并显示配速（单次+今日平均）
{ name: '跳绳', km: false }  // 只记分钟，不显示配速
```

配速无需额外开关：只要项目同时记录公里和分钟（km:true），即自动计算显示。
